# Маршрутизация курьерской доставки (лаба 4 — Security, я очень устал,босс)

REST-сервис учёта посылок и маршрутов с HTTP Basic Auth, CSRF и ролями.

## Роли

| Роль | Возможности |
| **ADMIN** | Все CRUD, пользователи, бизнес-операции |
| **OPERATOR** | Маршруты, остановки, назначения, посылки, бизнес-операции |
| **SENDER** | Регистрация, свои данные, просмотр/создание посылок |

Регистрация (`POST /api/auth/register`) всегда создаёт **SENDER**, роль ADMIN выдать себе нельзя.

Статус пользователя: `ACTIVE` / `BLOCKED`. Заблокированный не входит.

Пароли хранятся как BCrypt.

## Учётные записи по умолчанию

| Email | Пароль | Роль |
| admin@example.com | Admin123! | ADMIN |
| operator@example.com | Operator1 | OPERATOR |
| sender@example.com | Sender123 | SENDER |

## CSRF

1. `GET /api/auth/csrf` — получить токен  
2. В POST/PATCH/DELETE передать заголовок `X-XSRF-TOKEN: <token>` (и cookie, если клиент её сохранил)

## Ошибки

| Код | Смысл |
| 401 | Не аутентифицирован |
| 403 | Нет прав |
| 409 / 400 | Бизнес-ограничение или валидация |
